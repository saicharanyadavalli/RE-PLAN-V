Architectural Integrity & The 10 Inviolable Rules

RE-PLAN-V is built strictly on formal symbolic authority. All neural proposals are treated as unverified advice until formally checked against transition semantics.

Rule 1: Symbolic Authority

Symbolic layer is sole ground truth for state, validity, and action definitions.

Rule 2: Untrusted Neural Components

LLMs/VLMs never verify plans or declare validity. They only propose schemas.

Rule 3: Single Transition Semantics

Planner and verifier execute identical code for apply_transition.

Rule 4: Explicit Data Contracts

Every inter-module boundary validated via strict Pydantic models.

Rule 5: Actionable Counterexamples

Every verification failure produces a witness state trace and violated precondition.

Rule 6: Evidence-Based Attribution

Fault attribution classifies into 5 distinct categories with confidence scores.

Rule 7: Targeted Symbolic Repair

Repairs inject symbolic constraints rather than blind unguided regeneration.

Rule 8: Zero Fabricated Metrics

Every metric in benchmarks and reports is directly measured from execution.

Rule 9: Zero-API Core Operation

Fully offline and testable without external network dependencies or API keys.

Rule 10: Strict Bounded Repair Loops

Max iterations and loop detection guards guarantee termination.
